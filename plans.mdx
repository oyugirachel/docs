## FAQ

<AccordionGroup>
  <Accordion title="Does the free plan require a credit card?" icon="credit-card">
    No. Sign up with your GitHub account or email — no payment information required for the Free plan.
  </Accordion>
  <Accordion title="Can I scan private repositories on the free plan?" icon="lock">
    Yes. Private GitHub repository scanning is available on all plans (with your own GitHub token). The plan limit applies to the number of scans, not repository visibility.
  </Accordion>
  <Accordion title="Do AI features require my own Anthropic API key?" icon="key">
    AI features (explain, fix, triage, agent) use your Anthropic API key, which you provide. Your usage is billed directly by Anthropic based on tokens used. ZenVeil does not add a markup on AI usage.

    Alternatively, the ZenVeil API provides AI analysis without requiring you to manage your own key — usage is included in your plan's AI request allowance.
  </Accordion>
  <Accordion title="What happens if I exceed my scan limit?" icon="gauge">
    On Free and Pro plans, scans beyond the daily limit return an error. Your existing scan cache and all other commands (list, explain, fix, etc.) continue to work. Upgrade your plan to increase limits.
  </Accordion>
  <Accordion title="Is there a self-hosted option?" icon="server">
    The Python CLI and scanning API are open-source and can be self-hosted. The web dashboard, billing, and AI features require a ZenVeil subscription. Contact `hello@zenveil.dev` for enterprise pricing on fully self-hosted deployments.
  </Accordion>
  <Accordion title="Do you offer discounts for startups or open source?" icon="hand-holding-heart">
    Yes. Email `hello@zenveil.dev` with your project details:
    - Open source projects: Free Pro plan
    - Early-stage startups (< $1M ARR): 50% discount
    - Non-profits: Free Pro plan
  </Accordion>
</AccordionGroup>
